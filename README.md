# Minha Landing Page

## Landing page pessoal estilo "link in bio", com efeito glitch no título e um mini-game interativo.

🔗 **Site no ar:** <a jmelissacruz.is-a.dev a>

## O que tem na página

- Header com título e efeito glitch/distorção em RGB
- Foto de perfil
- Links para LinkedIn, Instagram e GitHub
- Footer com contato por e-mail e WhatsApp
- Mini-game "Colete 100 Data Pixels" — pixels caem na tela e você usa as setas do teclado (← →) para coletá-los

## Tecnologias

- HTML5
- CSS3 (sem frameworks)
- JavaScript puro (vanilla JS)
